🔄 Synchronisation (extension navigateur)

Token pour l'extension « Crowdfunding Tracker Sync » (Paramètres de l'extension → coller le token). Aucun mot de passe requis côté extension.

📦 Installation de l'extension

Téléchargez et installez l'extension de capture (v1.5.5) :

🌐 Chrome / Edge / Brave (.zip) 🦊 Firefox (.zip)

Chrome/Edge/Brave : extraire le zip → chrome://extensions → Mode développeur → « Charger l'extension non empaquetée » → choisir le dossier.
Firefox : about:debugging → Ce Firefox → « Charger un module temporaire » → sélectionner manifest.json (répéter après chaque redémarrage de Firefox).

💾 Sauvegarde & restauration

Sauvegardez toute votre base (projets, opérations, réglages) dans un fichier JSON — restauration complète à tout moment.

📤 Export

Télécharger tous les projets avec leurs indicateurs calculés (CSV compatible Excel).
